# Goud & Bitcoin Dashboard

Historische vergelijking van goud en Bitcoin met Nederlandse huizenprijzen, inflatie en andere referentiereeksen.

## Status

Project in opbouw. Eerste scope: goud versus Nederlandse huizenprijzen (maanddata vanaf januari 2000, EUR).

## Werkwijze

Wijzigingen verlopen via feature branches en pull requests. Geen API-sleutels of ruwe privédata in de repository. Deployment en databronnen worden pas geactiveerd na validatie.
